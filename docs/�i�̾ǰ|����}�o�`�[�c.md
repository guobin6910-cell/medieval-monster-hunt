# 《勇者學院：畢業之證》完整遊戲開發總架構

> 副標：想成為勇者，先通過所有考試。  
> 引擎：RPG Maker MZ｜平台：Windows 優先｜專案路徑：`D:\小遊戲\Project5`

---

## 0. 一句話定位

這是一款「校園考試型日式 RPG」：探索校園 → 找老師 → 四選一答題 → 無論對錯都進戰鬥 → 答錯必須重答同題 → 集齊學科徽章 → 年級 Boss → 通行證 → 下一年級 → 最終取得【勇者之證】。

不是純教育軟體，也不是普通魔王冒險；問答是戰鬥優勢的來源，戰鬥是答題的代價與節奏。

---

## 1. 完整主線流程

```
序章（學院外／夢想與吐槽）
→ 入學典禮（校長說明「勇者之證」）
→ 一年級校園自由探索
→ 完成 6 位老師 × 10 題
→ 一年級綜合考 Boss（教務主任・考試監督者）
→ 取得【一年級通行證】
→ 二年級～六年級（同架構擴充）
→ 勇者實習章節
→ 勇者之塔（綜合 10 題）
→ 最終 Boss：無知之王・空白魔王
→ 取得【勇者之證】
→ 畢業典禮
→ 真正的冒險開始（後記／二周目入口）
```

### 1.1 核心循環（每位老師）

```
對話老師 →【開始考試／稍後再來】
→ 顯示第 N／10 題（四選一）
→ 判斷答案
   ├─ 答對：正確演出＋解析＋增益／敵弱化＋戰鬥
   │         勝利 → 發該題獎勵（若有）→ N+1
   └─ 答錯：錯誤演出＋解析＋依次數扣 HP（至少留 1）＋劣勢戰鬥
             勝利 → 不前進 → 重答同一題
→ 10 題全對 → 學科徽章＋稀有裝備＋老師完成鎖定（不可重刷）
```

### 1.2 年級完成條件

- 該年級所有必修老師 `Switch[老師完成]=ON`
- 開放綜合考入口
- 擊敗年級 Boss → `Switch[年級完成]=ON`＋通行證 Key Item／Armor
- 解鎖下一年級地圖轉移

## 6. 題庫資料格式（JSON）

檔案：`data/quiz/grade1.json`（之後 `grade2.json`…）

```json
{
  "grade": 1,
  "teachers": [
    {
      "teacherId": "G1_CH",
      "subject": "國文",
      "name": "賽琳娜老師",
      "mapId": 4,
      "badgeItemId": 61,
      "clearSwitchId": 41,
      "progressVarId": 41,
      "questions": [
        {
          "id": "G1-CH-001",
          "question": "下列哪一個成語形容做事非常謹慎？",
          "options": ["粗心大意", "小心翼翼", "狼吞虎嚥", "走馬看花"],
          "answer": 1,
          "explain": "小心翼翼形容舉動十分謹慎，絲毫不敢疏忽。",
          "correctMsg": "回答正確！看來你有認真上課。",
          "wrongMsg": "回答錯誤！正確是：小心翼翼。",
          "troopIdCorrect": 51,
          "troopIdWrong": 52,
          "reward": {"type": "item", "id": 21, "amount": 1},
          "wrongHpRate": [10, 15, 20, 10]
        }
      ]
    }
  ]
}
```

規則：
- `answer` 為 0–3
- 同老師 10 題 ID 唯一；全遊戲題幹盡量不重複
- 答錯扣血百分比陣列對應第 1/2/3/4+ 次
- 扣血後 HP 下限 = 1

## 7. 答對／答錯流程（實作層）

### 7.1 答對
1. SE 正確音效  
2. 顯示正確＋解析  
3. 套用戰鬥前增益（ATK/MAT 上升或敵弱化）  
4. `Battle Processing` → `troopIdCorrect`  
5. 勝利後發該題獎勵（僅首次）  
6. 題號 +1；若題號 >10 → 老師完成處理  

### 7.2 答錯
1. SE 錯誤音效  
2. 顯示正確答案＋短解析  
3. 依答錯次數扣最大 HP%（留 1）  
4. 套用劣勢（敵先制／玩家弱化）  
5. `Battle Processing` → `troopIdWrong`  
6. 勝利後 **不** +1；重開同題  
7. 若 HP 過低 → 提示去保健室（免費回復）

### 7.3 防卡關
- 圖書館賣／領「學科筆記」「智慧藥水」：顯示提示或排除一錯誤選項  
- 保健室免費回復（考試期間）  
- 答錯永不 Game Over

## 8. 戰鬥系統連結

| 結果 | 戰鬥修正 | 敵人 |
|---|---|---|
| 答對 | 玩家先攻、敵 HP -20% 或 Def Debuff、玩家小回復 MP | 知識魔物（弱化版 troop） |
| 答錯 | 已扣 HP、敵先攻或敵 ATK Up、玩家可能 Panic/Silence 1 回合 | 失控知識魔物（強化版 troop） |

知識魔物族（複用既有 battler 圖）：
- 國文：文句幽靈、錯字史萊姆  
- 數學：算術魔像、分數史萊姆  
- 歷史：遺忘亡靈  
- 地理：地圖魔獸  
- 自然：元素史萊姆  
- 魔法：失控魔導書

### 9.1 學科徽章（建議 Armor 或 Key Item＋狀態）

每題可給消耗品／素材；老師通關給稀有武器／防具；年級通關給通行證。

### 9.3 不可重刷
`Switch[老師完成]` ON 後老師對話改為完成台詞，獎勵事件跳過。

## 12. 主線劇情三段式

- **前期**：輕鬆搞笑校園、考試吐槽、老師個性、同學日常  
- **中期**：知識魔物異常、學生傳言、圖書館禁書、學院建於古代遺跡  
- **後期**：勇者之證＝封印鑰匙、高層企圖啟動古代核心、畢業試煉中拯救學院  

一年級需埋的伏筆（不揭穿）：
1. 圖書館「禁閱區」上鎖  
2. 老師對魔物來歷欲言又止  
3. 校長提到「證」時眼神閃爍  

---

## 13. 支線（一年級至少 3）

1. 找不到教室的新生 → 帶路 → 回復藥  
2. 小賣部幫忙進貨 → 折扣券／筆記  
3. 訓練場與同學切磋（固定 troop）→ 小額金錢  

皆一次性 Switch。
